# Data Structures and Algorithms in Java

A complete implementation of fundamental Data Structures and Algorithms using pure Java without relying on Java Collections Framework.

## Implemented Data Structures

### Linear Data Structures

- Array List
- Singly Linked List
- Circular Linked List
- Stack
- Queue
- Linked Stack
- Linked Queue

### Non-Linear Data Structures

- Binary Search Tree (BST)
- Heap
- Map
- Set

---

## Implemented Algorithms

### Searching

- Linear Search
- Binary Search

### Sorting

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort
